# d2l-learning

《动手学深度学习》（D2L）学习笔记与代码实现。

## 目录结构

```
aNotes/       学习笔记（Jupyter Notebook）
  ├── 01pytorch基础/       PyTorch 基础操作
  ├── 02线性神经网络/      线性回归、Softmax 回归、图像分类数据集
  └── ...
d2l-course/   D2L 官方课程代码
data/        数据集（不入库，可重新下载）
```

## 使用

```bash
pip install d2l torch torchvision
```

运行对应章节的 `.ipynb` 文件即可。
